# CENTER

CENTER is an immersive 3D vocal composition created for the Tenth Student 3D Audio Production Competition. The work explores the idea of love as an emotional center through spatial audio, using only the human voice as sound material.

The composition was produced in 5th Order Ambisonics using the Ambix convention (ACN/SN3D) and rendered for both binaural headphone playback and loudspeaker-based immersive reproduction.

## Listening Instructions

### Binaural Version

For the best experience, listen to **CENTER_Binaural.wav** using stereo headphones in a quiet environment. The binaural render reproduces the intended spatial movements and immersive effects of the composition.

### Ambisonics Version

The file **CENTER_Ambisonics_5OA_Ambix.wav** is the original 5th Order Ambisonics master and is not intended for direct stereo playback.

To experience the Ambisonics version correctly, decode it using compatible Ambisonics software or playback systems supporting Ambix (ACN/SN3D). The file can also be rendered to loudspeaker configurations such as 7.1.4 or other immersive audio systems.

## Production Details

* Format: 5th Order Ambisonics (Ambix, ACN/SN3D)
* DAW: REAPER
* Spatial Audio Plugins: IEM Plugin Suite
* Rendering Formats:

  * Ambisonics Master
  * Binaural Headphone Render

## Concept

The entire composition is created using the human voice, including lead vocals, harmonies, vocal bass, percussion, ad-libs, and vocal chops. Spatial movement, elevation changes, width modulation, and immersive reverberation are used to reinforce the emotional narrative and create a three-dimensional listening experience.
